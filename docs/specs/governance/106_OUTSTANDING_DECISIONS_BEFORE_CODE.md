# MinaDent V1.6 — Outstanding Decisions Before Code

## Purpose
List decisions that still need resolution before implementation can safely start.

## Must decide before repo/init or Phase 1 code
1. SDK path: Expo Go SDK54-compatible vs development build path.
2. App identity: name, slug, package/bundle IDs, owner account.
3. First Phase 1 scope: exact screens/components allowed.
4. Design references: which screenshots/patterns are approved for structural inspiration.
5. Project root path and Replit identity guard.

## Must decide before schema/data
1. Final active doctors.
2. Final staff and roles.
3. Unit names/colors.
4. Work hours/closure policy.
5. File number policy.
6. Required patient fields.
7. Doctor share formulas.
8. Lab names and cost rules.
9. Treatment/service catalog MVP.
10. Payment methods MVP.

## Must decide before integrations
1. SMS provider.
2. WhatsApp strategy.
3. Payment gateway.
4. Backup destination.
5. Push notification path.
6. Insurance/Salamat feasibility.

## Must decide before AI
1. AI allowed actions.
2. Human approval rules.
3. Clinical disclaimer.
4. Audit requirements.
5. Data privacy boundaries.

## Decision rule
If a decision affects schema, security, money, patient health, or runtime compatibility, guessing is forbidden.
