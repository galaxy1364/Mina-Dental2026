# 87 — Module Detail Depth Requirement Catalog
Version: V1.5
Status: LOCKED REQUIREMENT DEPTH

## Purpose
The user should not have to remember every feature. MinaDent must maintain deep module catalogs so Replit cannot build shallow modules.

## Scheduling depth
Must include: doctor, unit, appointment type, duration presets/custom, Jalali date, time slot, manual time, conflict, waiting list, holidays, closed day override, doctor leave, unit capacity, incoming call quick create, provisional patient, no-show, reschedule, cancel reason, arrival, waiting, in-treatment, completed, follow-up scheduling, daily/weekly/monthly/yearly/doctor/unit views.

## Patient depth
Must include: file number, mobile normalization, national code validation, duplicate warnings, family/referrer, medical history, allergies/medications, imaging, timeline, debt status, follow-up, archive/reactivation, consent, signature/fingerprint/photo hooks.

## Treatment depth
Must include: tooth/area/surface, procedure, material, doctor, assistant, lab link, implant stage, cost, discount, outcome, next step, prescription, attachment, before/after images, revision history.

## Finance depth
Must include: invoice, payment, discount, debt, installments, cheques, POS/cash/transfer, receipt image, doctor share, lab cost, implant exception, manager-only sensitive edits, audit, reports.

## Lab depth
Must include: lab order, item, tooth, shade, material, due date, sent/received/delivered/remake, lab cost, doctor/patient link, delayed alerts.

## Dashboard depth
Must include: today schedule, arrivals, pending actions, debts, checks/installments, lab delays, recalls, sync/backup health, doctor capacity, alerts, role-aware KPI, click-through to module.

## AI depth
Must include: command parser, preview, confirmation, RBAC, audit, human approval, safe failure, no clinical final decision, no destructive action by default.

## Design depth
Every module must have: top command/search, chip rail, cards, status colors, empty/loading/error/offline states, bottom sheet actions, dock behavior, RTL, Jalali, accessibility.
