# MinaDent V1.6 — MVP Release 1 Scope Lock

## Purpose
Define the first valuable, testable, real release path without feature sprawl.

## Release 1 mission
Deliver a real Persian-first, offline-capable, clinic-grade core that proves the foundation and the highest-priority workflows.

## Release 1 phases

### R1-0 Governance and repo identity
Read-only audit, SDK runtime decision, repo creation plan.

### R1-1 Production App Shell
RTL, banking-grade shell, dashboard preview, dock, cards, states, Expo Go 54 phone preview.

### R1-2 Local data foundation
SQLite, migrations framework, offline queue foundation, local seed only for safe clinic settings.

### R1-3 Auth and role shell
Login/session, manager/doctor/secretary role separation, no finance leak.

### R1-4 Patient Master MVP
Patient create/search/detail/edit/archive, file number, mobile/national code, duplicate warnings, offline queue.

### R1-5 Smart Scheduling MVP
Jalali calendar, doctor/unit, type/duration, conflict detection, free slot, arrival status.

### R1-6 Patient Journey MVP
Timeline/stepper: contact → file → appointment → arrival → treatment → finance → follow-up.

### R1-7 Finance MVP
Invoice, payment, debt, installment/cheque basic, manager-only sensitive actions.

### R1-8 Lab MVP
Lab order status, due date, delay warning, link to patient/treatment/finance.

### R1-9 Backup/sync evidence
Backup/restore drill, sync queue evidence, conflict visibility.

## Not Release 1
- AI X-Ray diagnosis.
- AR dental.
- GraphQL/codegen automation.
- SaaS subscription plans.
- Smart contracts/blockchain.
- Direct Salamat integration.
- Production payment gateway unless officially verified.

## Rule
A future feature can be visually reserved as a disabled slot only if it has a backlog ID and no dead action.
