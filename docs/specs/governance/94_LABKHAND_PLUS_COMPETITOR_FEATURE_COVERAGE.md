# 94 — Labkhand+ Competitor Feature Coverage
Version: V1.5
Status: LOCKED MARKET COVERAGE

## Purpose
Ensure MinaDent covers and exceeds competitor dental management capabilities through governed requirements, not blind cloning.

## Minimum coverage inspired by public competitor features
MinaDent must cover:

- patient file creation;
- quick patient search;
- multi-doctor/multi-unit support;
- appointment scheduling;
- dental chart and treatment history;
- insurance/tariff capability;
- electronic consent/signature/fingerprint/photo hooks;
- finance/debt/payment;
- lab and inventory hooks;
- reporting;
- backup;
- Persian UX.

## MinaDent must exceed through

1. Offline-first mobile app.
2. Live patient journey timeline.
3. Phone-first command center.
4. Role-aware dashboard.
5. Advanced RBAC/audit.
6. Smart scheduling with capacity/conflicts.
7. Implant/lab/finance attribution.
8. AI-assisted but human-approved commands.
9. Expo phone preview gates.
10. Governance ZIP/source-of-truth updates after every step.

## Acceptance rule
Any competitor feature accepted into MinaDent must have:

```text
Requirement ID
Module
Phase
MVP/Future classification
Data contract
Screen contract
Test plan
Evidence requirement
Risk classification
```
