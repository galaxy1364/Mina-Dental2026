# 81 — World-Class Research & Benchmark Pipeline
Version: V1.5
Status: LOCKED GOVERNANCE

## Purpose
The user has explicitly stated that their mind is limited and the system must not rely only on user-described features. MinaDent must continuously extract best practices from credible global, Iranian, clinical, mobile, banking-grade, accessibility, security, performance, and dental-management references.

## Research source hierarchy
Use this order:

1. Official standards and primary documentation.
2. Peer-reviewed or standards-backed guidance.
3. Official product documentation and app-store feature descriptions.
4. Competitor public feature pages.
5. User-provided screenshots/files.
6. AI inference, only after marking it as inference.

## Mandatory research domains before each major module
Each module must be researched against at least these domains:

- Global healthcare scheduling models.
- Dental clinic management systems.
- Iranian clinic workflow norms.
- Persian/RTL/Jalali constraints.
- Security/privacy constraints.
- Performance at 200k+ patient scale.
- Banking-grade mobile UX patterns.
- Accessibility and touch ergonomics.
- Offline-first and sync conflict patterns.

## Output of research
Research is not a chat note. It must produce structured records:

```text
RESEARCH-ID
Source
What was learned
MinaDent implication
Module affected
Accept / Rewrite / Reject / Future
Evidence required
File(s) to update
```

## Research-to-requirement flow
```text
Research finding → Requirement ID → Traceability Matrix → Module Blueprint → Data Contract → Screen Contract → Test Matrix → Execution Packet
```

## No blind benchmark copying
Banking apps and dental competitors may inspire structure, flow, density, component hierarchy, and trust cues. Brand names, logos, exact copy, proprietary visuals, and protected assets must not be copied.

## Re-search trigger
Re-search is mandatory when any of these occurs:

- new SDK/tooling decision;
- payment/SMS/insurance/API integration;
- AI clinical feature;
- security/privacy feature;
- major UI foundation;
- new competitor/benchmark file;
- any user says: “جهانی”، “بهترین”، “آخرین”، “فوق پیشرفته”، or “مثل اپ ...”.
