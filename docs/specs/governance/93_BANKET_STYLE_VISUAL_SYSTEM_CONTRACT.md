# 93 — Banqet/Banking-Style Visual System Contract for MinaDent
Version: V1.5
Status: LOCKED VISUAL TARGET

## Purpose
Capture the user's visual target in engineering language: MinaDent must feel like a premium, fast, high-trust Iranian banking app, adapted to a dental clinic control tower.

## Visual traits to target
- premium Persian-first interface;
- dense but readable cards;
- strong top-level command/search;
- trust and status indicators;
- polished bottom navigation;
- smooth micro-interactions;
- clear hierarchy;
- rounded premium cards;
- soft surfaces/glass-like layers where performance-safe;
- large readable module icons;
- minimal scroll on primary views;
- every card actionable.

## MinaDent translation
Banking account overview becomes clinic operations overview.
Banking transaction list becomes patient timeline and financial timeline.
Investment/payment shortcuts become appointment/patient/finance/lab quick actions.
Security/verification cues become sync/backup/audit/RBAC status.

## First shell visual contract
The first visible shell must have:

1. App identity header.
2. Smart command/search area.
3. Today's clinic control summary.
4. Patient journey card.
5. Appointment capacity card.
6. Finance/debt risk card.
7. Lab/implant pending card.
8. Follow-up/recall card.
9. Sync/backup health card.
10. Bottom dock with canonical icons.

## Design safety
No exact copy of Banket screens, colors, illustrations, names, or branding. Use structural inspiration only.
