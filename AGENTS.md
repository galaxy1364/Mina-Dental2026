# Expo SDK is LOCKED to 54

This project targets **Expo SDK 54** (React Native 0.81). The target device runs
**Expo Go 54.0.8**, which only loads SDK 54 projects, so the SDK is intentionally
pinned to 54 — do not upgrade to 56 or drift versions.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before
writing any code.
